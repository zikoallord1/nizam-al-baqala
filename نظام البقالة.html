  • جوال المدير يفتح الـ APK → يشوف التقارير لحظياً من السحابة

الحل 1: ترجمة تلقائية من ويندوز (الأسهل)

  1. افتح GitHub Desktop
  2. اضغط على متصفح Edge أو Chrome
  3. نزل إضافة Google Translate
  4. افتح GitHub Desktop؟ لا، هذه الطريقة ما تشتغل معه لأنه برنامج وليس موقع.

الحل الصحيح:

GitHub Desktop نفسه ما يتعرب، لكن موقع GitHub اللي ترفع عليه تقدر تعربه:

  1. افتح موقع github.com في متصفح Google Chrome
  2. كليك يمين في أي مكان فاضي في الصفحة
  3. اختر ترجمة إلى العربية
  4. بيتحول الموقع كله عربي - الأزرار، القوائم

الحل 2: تغيير لغة الويندوز كامل للعربي (يخلي بعض البرامج تحاول تتعرب)

  1. ادخل الإعدادات Settings في الويندوز
  2. Time & Language > Language
  3. اضغط Add a language > اختر العربية
  4. خليها اللغة الأساسية
  5. أعد تشغيل الجهاز
  6. بعض أجزاء GitHub Desktop بتتحول عربي تلقائياً

الحل 3: استخدم بديل عربي 100% (أنصحك به)
